## Overview

**GitHub** is a cloud-based platform built around **Git**, a distributed version control system. It allows developers to store, manage, track, and collaborate on code from anywhere in the world. Beyond hosting source code, GitHub provides tools for project management, code review, continuous integration/continuous deployment (CI/CD), and open-source community building.

---

## Core Concepts: Git vs. GitHub

Understanding GitHub requires distinguishing between the underlying tool and the hosting platform:

| Feature | Git | GitHub |
| :--- | :--- | :--- |
| **What it is** | Distributed version control software | Cloud-based hosting service for Git repositories |
| **Where it runs** | Locally on your computer | Online (web interface, desktop app, CLI, API) |
| **Primary Function** | Tracks file changes and manages commit history | Hosts remote repositories and enables collaboration |
| **Cost** | Free and open-source | Free tier available; paid tiers for advanced enterprise features |

## Key Terminology

* **Repository (Repo):** A project folder that contains all project files along with each file's revision history.
* **Commit:** A saved snapshot of your changes at a specific point in time, accompanied by a descriptive message.
* **Branch:** An independent line of development. The default primary branch is typically named `main`.
* **Clone:** Creating a local copy of a remote GitHub repository on your machine.
* **Fork:** Creating a personal copy of someone else's repository under your own GitHub account to propose changes or build upon their work.
* **Pull Request (PR):** A formal request to merge changes from one branch (or fork) into another, initiating code review and discussion.
* **Merge:** Integrating changes from one branch into another.
* **Issue:** A tracking mechanism for bugs, feature requests, tasks, and project discussions.

## How the GitHub Workflow Works

The standard collaborative model—known as the **GitHub Flow**—follows six core steps:


Collaboration & Automation Features
GitHub Actions: Built-in CI/CD engine that automates testing, building, and deployment workflows triggered by events like pushes or pull requests.

GitHub Issues & Projects: Kanban boards, tables, and milestone trackers integrated directly with code commits and pull requests.

GitHub Pages: Free static site hosting directly from a repository's files (commonly used for documentation and portfolios).

Security & Dependabot: Automated vulnerability scanning and pull requests that keep project dependencies up to date.

GitHub Copilot: AI-powered coding assistant integrated into editors and the GitHub web interface.
